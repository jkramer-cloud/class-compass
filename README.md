# Class Compass — Student Planner v1.2

A static, account-free student planner for Grades 5–12. Upload `index.html` to a standalone GitHub Pages repository. No server, Google sign-in, or external libraries are required.

## New in v1.2

- Student name in the first-run setup and Settings; displayed on weekly planner PDF reports.
- Weekly PDF reports request a name for personal-mode submissions.
- School-year archive and rollover in Settings. Download a full backup when archiving the current year, then begin a new year with a clean task list and a copied, editable class schedule.
- Read-only archived-year summaries, separate archive JSON downloads, and full backup exports that include all archived years.
- Existing v1.1 local data and imports remain compatible.

## Important

No Google sign-in or account means **no automatic syncing between devices**. The app uses browser localStorage; some district-managed Chromebooks erase browser data when signing out. Students should regularly use Settings > Export full backup and keep the JSON backup somewhere the school's IT policy permits. The app does not verify the accuracy of student-entered activity.

**Archive caution:** At year end, the archive button downloads a full JSON backup and saves a history snapshot locally. Save that downloaded backup securely, because browser storage alone is not a long-term guarantee. The archived year's complete data can be exported from the archive list. Do not delete the JSON backup.

This pilot includes fictional demo data dated through November 13, 2026, separate from personal planner data. Demo reports are stamped SAMPLE. The 2027–28 community calendar appears to have conflicting spring-break indications and should be checked against the district's definitive calendar.
